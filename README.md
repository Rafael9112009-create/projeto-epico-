# 🤸 Projeto: Flip Challenge — Homens dando mortais

## 📋 Sobre o projeto

O Flip Challenge é um sistema desenvolvido para apresentar, organizar e acompanhar desafios de acrobacias, com foco em homens realizando mortais para frente e para trás.

O site permite que o usuário cadastre desafios, visualize os movimentos registrados, edite suas informações, marque desafios como concluídos e exclua aqueles que não deseja mais manter.

## 🎯 Objetivo

O objetivo do projeto é criar um site interativo, colorido e fácil de utilizar, com um visual moderno, cantos arredondados e cores pastéis.

O sistema será voltado à organização de desafios de acrobacias, oferecendo uma interface simples para registrar movimentos, acompanhar o progresso e gerenciar uma lista de desafios.

## ⚙️ Funcionalidades

- Cadastrar desafios: adicionar um novo desafio de mortal, informando o nome do movimento e sua descrição.
- Visualizar desafios: consultar todos os movimentos cadastrados.
- Editar desafios: alterar o nome, a descrição ou o tipo de mortal.
- Concluir desafios: marcar um movimento como concluído.
- Excluir desafios: remover movimentos que não sejam mais necessários.
- Filtrar desafios: visualizar todos os desafios, os pendentes ou os concluídos.
- Acompanhar progresso: visualizar quantos desafios foram concluídos.

## 👤 Usuário

O sistema possui um único ator principal:

Usuário: responsável por cadastrar, visualizar, editar, concluir e excluir desafios de mortais.

## 🖥️ Como utilizar

1. Acesse o site Flip Challenge.
2. Clique em Novo desafio.
3. Informe o nome do movimento, por exemplo, “Mortal para trás”.
4. Adicione uma descrição e selecione o tipo de acrobacia.
5. Salve o desafio para adicioná-lo à lista.
6. Edite as informações ou marque o desafio como concluído quando desejar.
7. Exclua os desafios que não forem mais necessários.

## 📌 Requisitos do sistema

O sistema deve permitir que o usuário:

- Cadastre novos desafios de acrobacias;
- Consulte os desafios cadastrados;
- Altere as informações dos desafios;
- Marque desafios como concluídos;
- Remova desafios da lista;
- Filtre os desafios por situação;
- Consulte seu progresso geral.

## 💾 Armazenamento de dados

Os desafios devem permanecer salvos para que o usuário possa consultar sua lista mesmo após fechar e abrir novamente o site. Para uma versão simples, pode-se utilizar o `localStorage` do navegador.

## 🛠️ Tecnologias sugeridas

- HTML5: estrutura das páginas.
- CSS3: cores pastéis, cartões arredondados e layout responsivo.
- JavaScript: cadastro, edição, exclusão, filtros e conclusão dos desafios.
- LocalStorage: armazenamento dos desafios no navegador.

## ✅ Resultado esperado

Ao final, o projeto deverá apresentar um site funcional no qual o usuário possa organizar seus desafios de mortais em uma interface esportiva, agradável e intuitiva, com operações simples de cadastro, edição, conclusão e exclusão.

O projeto pode ser desenvolvido inicialmente como um site estático, sem necessidade de cadastro ou login.
